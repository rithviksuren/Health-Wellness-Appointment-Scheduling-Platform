# User Manual

## Donors

Donors can browse campaigns, make one-time or recurring donations, view donation history, download receipts, and manage communication preferences.

## Campaign Managers

Campaign managers can create campaigns, publish campaigns, update project details, and monitor funding progress.

## Treasurers

Treasurers can view financial reports, donor summaries, donation trends, project funding reports, and report exports.

## Admins

Admins can manage users, roles, account status, integrations, and audit activity.
